# Iris Dataset EDA
This notebook contains an exploratory data analysis (EDA) of the Iris dataset, which is a classic dataset in machine learning and statistics. The dataset consists of 150 samples of iris flowers, with four features (sepal length, sepal width, petal length, and petal width) and a target variable indicating the species of the iris (setosa, versicolor, or virginica).

## EDA Summary
1. The target variable is balanced, with each class having 50 samples.
2. There are no missing values in the dataset.
3. Histograms of each feature show that the distributions are different for each species, particularly for petal length and petal width.
4. Scatter plots and pairplots reveal clear separation between the species based on the features, especially between setosa and the other two species.
5. The correlation matrix indicates strong correlations between petal length and petal width, which are informative for distinguishing between the species.
